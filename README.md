# axel69390.github.io

Racine GitHub Pages du compte. Sert uniquement à publier `/.well-known/assetlinks.json`,
qui autorise l'application Android **CardVault** (`io.github.axel69390.cardvault`) à afficher
https://axel69390.github.io/pokemon-tracker/cardvault/ en plein écran (Trusted Web Activity).

`.nojekyll` est indispensable : sans lui, GitHub Pages ne publie pas les dossiers commençant par un point.
